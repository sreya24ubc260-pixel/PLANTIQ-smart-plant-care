# PLANTIQ — Futuristic Plant Care App

A premium dark futuristic redesign of the Plant Care Assistant.

## Features
- Futuristic dark command-center UI
- Plant health score ring
- Moisture, sunlight, humidity and temperature metrics
- Interactive Water action
- AI Analysis screen
- Simulated asynchronous scan using `Future`, `async`, `await`
- System status screen
- Bottom navigation
- No external API or extra package required

## Run

```powershell
flutter pub get
flutter run -d chrome
```

You can also run it on an Android device once the Android SDK is configured.

## Assignment concepts demonstrated
- `Future`
- `async`
- `await`
- `Future.delayed()`
- ternary operator
- null-aware operator `??`
- collections and conditional UI
- Rows, Columns, Containers, Lists
- navigation through bottom navigation
